# tlzkrh1029.github.io

Claude와 ChatGPT로 만든 웹페이지와 아티팩트를 한곳에 모아 보여 주는 허브입니다. 주소는 https://tlzkrh1029.github.io/ 입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `works.json` | 작품 목록입니다. 번호, 암구어, 제목, 주소, 스크린샷, 플랫폼, 제작 도구, 날짜, 설명을 적습니다. |
| `tools/build.py` | `works.json`을 읽어 `index.html`을 만듭니다. |
| `index.html` | 생성된 페이지입니다. 직접 고치지 않고 `tools/build.py`로 다시 만듭니다. |
| `assets/hub.css`, `assets/hub.js` | 벽, 벽 아래 설명, 대문의 화면과 동작입니다. 이 파일을 고친 뒤에도 `tools/build.py`를 다시 실행합니다. 그래야 `index.html`에 붙는 버전 표시(`?v=...`)가 바뀌어서, 방문자의 브라우저가 예전 파일을 쓰지 않습니다. |
| `assets/shots/` | 작품 스크린샷(800×600)입니다. |
| `assets/og.jpg`, `assets/favicon.svg` | 링크 미리보기 이미지와 탭 아이콘입니다. |

## 벽과 전시실

- 전시실의 첫 화면은 작품이 걸린 벽 하나입니다. 대문은 이 벽 위에 어둠과 조명만 덮은 화면이므로, 대문에서 불을 켜면 작품이 조명이 비추던 자리에 그대로 걸려 있습니다.
- 벽에는 `works.json`의 앞 9개 작품이 걸립니다. 자리는 `assets/hub.css`의 `.p1`부터 `.p9`까지가 정하며, 가로 화면용 값과 세로 화면용 값이 따로 있습니다. 각 자리는 액자 가운데의 위치(`--x`, `--y`, 벽 크기에 대한 %)와 액자 폭(`--w`, 벽 폭에 대한 %)으로 적습니다.
- 가로가 세로의 1.95배보다 넓은 화면에서는 액자 크기가 화면 높이를 따릅니다. 그래서 아주 넓은 화면에서도 액자끼리 겹치는 정도가 더 커지지 않습니다.
- 액자마다 왼쪽 아래 모서리에 번호와 암구어가 금빛 기울임 글자로 적힌 작은 놋쇠 명판이 붙어 있습니다. 대문에서는 조명이 지나갈 때만 명판이 보입니다.
- 전시실에서 액자에 마우스를 올리면 그 액자가 앞으로 나오고 명판에 제목이 함께 나타나며, 나머지 액자는 어두워집니다. 액자를 누르면 작품이 새 탭에서 열립니다.
- 벽 아래의 Wall texts에는 모든 작품의 번호, 제목, 플랫폼과 날짜, 설명, 링크가 있습니다.

## 대문과 암구어

- 주소에 해시가 없으면 전시실 앞에 대문이 먼저 나옵니다. 대문은 불이 꺼진 전시실입니다. 전시실의 벽이 어둠에 덮여 있고, 조명 하나가 벽 위에서 타원을 그리며 천천히 움직입니다. 데스크톱에서는 마우스를 움직이면 조명이 따라옵니다.
- 가운데에는 그날의 문어(Tonight's challenge)가 나옵니다. 문어는 한국 시간 자정마다 바뀝니다. 단어 목록은 `works.json`의 `site.challenges`(60개)에 있고, `site.challenge_epoch` 날짜에 첫 단어가 나온 뒤 차례로 돌아갑니다.
- 답어 칸에 작품의 암구어(`RRG` 등)나 번호(`01` 등)를 입력하면 조명이 그 작품으로 옮겨 가고, 작품이 새 탭에서 열립니다. 아래 줄의 암구어를 눌러도 같습니다. `GITHUB`를 입력하면 저장소 목록이 열립니다.
- `WORKS`를 입력하거나, 빈칸에서 Enter를 누르거나, Esc를 누르거나, 문장 안의 WORKS를 누르면 불이 켜지면서 전시실로 들어갑니다.
- `#works`, `#rrg`, `#01` 같은 주소로 들어오면 대문을 건너뜁니다. `#rrg`, `#01`로 들어오면 벽에서 그 액자를 앞으로 꺼내 보여 줍니다. `#door`로 들어오면 언제나 대문이 열립니다.
- 전시실에서 `DOOR` 또는 `0`을 입력하면 벽으로 올라간 뒤 불이 꺼지면서 대문으로 돌아갑니다. 암구어나 번호를 입력하면, 벽이 보일 때는 벽에서 그 액자를 앞으로 꺼내 보여 주고, 벽 아래 설명을 보고 있을 때는 그 작품의 설명으로 이동합니다.
- 대문의 "Skip this door next time"을 켜면 그 브라우저에서는 대문을 건너뜁니다(localStorage의 `hub-door` 값).
- 움직임 줄이기 설정을 켠 브라우저에서는 조명이 스스로 움직이지 않고, 불이 켜지는 장면 없이 바로 전시실로 들어갑니다.
- 문어를 바꾸거나 늘리려면 `site.challenges`를 고친 뒤 `python3 tools/build.py`로 `index.html`을 다시 만듭니다. 목록의 길이가 바뀌면 날짜마다 나오는 단어도 달라집니다.
- 정적 사이트이므로 암구어는 바로 가기 역할만 하고, 접근을 막는 잠금은 아닙니다.

## 작품을 추가하는 방법

1. 스크린샷을 `assets/shots/<id>.jpg`(800×600)로 넣습니다.
2. `works.json`의 `works`에 항목을 추가합니다. 앞 9개 작품이 벽의 자리 `p1`부터 `p9`까지에 순서대로 걸리고, 10번째 작품부터는 벽 아래 설명에만 나옵니다. 가장 큰 자리는 `p1`이므로 대표작을 맨 앞에 둡니다. 걸리는 순서를 바꾸려면 `works`의 순서를 바꿉니다.
3. `python3 tools/build.py`를 실행해 `index.html`을 다시 만들고, 바뀐 파일을 함께 커밋합니다.
